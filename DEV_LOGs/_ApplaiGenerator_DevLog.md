# ApplaiGenerator's DEVELOPMENT LOG

* **[ApplaiGenerator Project Log](../../01%20DASHBOARD/PRJ-LOG/_FlClicker_Project_Log.md)**

This Log-folder for DEVELOPERS describes all the **changes made to the source-code** and therefore documents 
* developer goals, 
* architecural decisions
* software design sbtatements
* code related issues
* suggestions for code improvments
* decsions conerning development tools
* coding and testing progress, 
* fails and key lessons learned 

only when concerning the actual Codebase of THIS project. This also includes everything related to optimization, security, testing and deployment of the final software, as well everything related to code documentation (who, where, about what in which detail). 

## Monthly YYMM folders
Logfiles will be created, summarized and filed into **MMYY labeled monthly folders**. 

So, for instance, the **[/2603 folder](2608/260818_ApplaiGenerator_DevLog.md)** contains 

1. the [Monthly Summary]() and 

2. all the [260818 FlClicker DevLog](2608/260918_FlClicker_DevLog.md) for this month. 

All the logfiles will contain links to project artefacts and vice versa. Therefore it is paramount, that the location of these logs and such referred project artefacts remain unchanged.  

## Mind the Scope!
Everything what is PROJECT management realted, such as new or modified specifications, requirements, decisions made, milestones, planning etc. is logged in the [ApplaiGenerator's Project Logs](../../01%20DASHBOARD/PRJ-LOG/_FlClicker_Project_Log.md) in a similar file-structure within the [Project Dashboard folder](../../01%20DASHBOARD/_Project%20Dashboard.md)
