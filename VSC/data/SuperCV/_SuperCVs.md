# SuperCVs

This folder contains samples of [Reactive Resume](https://rxresu.me/) built "SuperCVs". 

**SuperCVs contains the full list of ALL experiences, skills etc**. from which the Applai-Generator will generate job-offer specific CVs which finally are subsets of the SuperCVs they have been created from. 

The SuperCVs are exported as *.pdf, *.docx, *.md and ".json. 

For the Applai-Generator only the JSON-format is relevant. 

This **SuperCV.json** will be uploaded (copy/pasted) into a personal -Repo from where it can be read by the client either natively or via a dedicated beckend server.
