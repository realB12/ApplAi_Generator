# Folder for the ApplaiGenerator's CLIENT Code 

The "client" represents the ApplaiGenerator's Front-End, where the user interacts with the App in his personal Browser. 

Developmentweise the Client includes a minimal backend-server that is used for rapid prototyping and testing but in a next phase will be replaced by a dedicated, full flown and maintained [Backend-Server](../server/_ApplaiGenerator%20SERVER%20Code.md) for better scalability, more security and better maintenance following best practices for large scale systems.
