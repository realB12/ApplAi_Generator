# KIMI Project Configuration Files

-> [KIMI Project Configuration File **Templates**](../../../../../../../../../../WORK/ENTITY/AI/PROVIDER/K/Kimi/CONFIG/KIMI%20Project%20Configuration%20Files.md)

The following AI configuration files are required by the Kimi (Vibe-)Code Generator to know and how to build stuff to meet our requirements. 

The sum of those files represent the highlevel specs for the such generated Application prototype and will remain relevant to represent the core principles upon what the app is built.

><span style="color:red; font-weight:bold">**ACHTUNG</span>: so you better some time to get those files right and you fully understand their meaning before prompting for the first time.**

Find the documented Templates in the [KIMI Service Description](../../../../../../../../../../WORK/ENTITY/AI/PROVIDER/K/Kimi/CONFIG/KIMI%20Project%20Configuration%20Files.md)

## List of Configuration Files

```plaintext
AI.KIMI/
│   
├── CHANGELOG.md
├── SESSION.md
├── README.md
│       
└── CONFIG/
    ├── VISION.md
    ├── SPEC.md
    ├── TECH.md
    ├── BOUNDARIES.md
    ├── PATTERNS.md
    └── DECISIONS.md
```

## How to use those configuration files
Rather than editing or loading them manually into the AI,  we set them up in the app's Source Repo, so that in the AI prompt we can simmply tell the AI where to find them.
