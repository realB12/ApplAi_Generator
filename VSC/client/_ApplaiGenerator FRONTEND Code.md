# Folder for the ApplaiGenerator's FRONT-END Code 

The "client"-folder contains the ApplaiGenerator's Front-End resp. Client-Code that handles user interaction in the browser whereas the [Backend or Server-Code](../server/_ApplaiGenerator%20Backend%20Code.md) is handled in the "/server" folder. 

Developmentwise the "client" includes a minimal backend-server as well: However this dev-Server is only used for rapid prototyping and testing and will be replaced by a dedicated, full blown and maintained [Backend-Server](../server/_ApplaiGenerator%20SERVER%20Code.md) for better scalability, more security and better maintenance following best practices for large scale systems.
