# ApplAI Change Request Templates

Change Request are "**CR-nnn-YYYYMMDD-[kebab-case-title].md**" names files in the 
[\CHANGES\REQUESTS](../_Collection%20of%20Change%20Requests.md) folder ordered by Request numbers in folders named "CR000" followed by "CR025" to contain requests with associated numbers. 

## Backlog
Ideas, Issues that will be implemented in a next version (or never) are parked in the **[BACKLOG](../../../BACKLOG/_ApplAI%20BACKLOG.md)**. When they become active, they will be copied to the [Change Folder](../../_Documenting%20Changes%20and%20Improvements.md)
